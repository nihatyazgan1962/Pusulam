# 🧭 Pusulam — Yaşamı ve Kalbi Hizalayan Rehber

Kıble pusulası, namaz vakitleri ve zikirmatiği; adım, su takibi ve günlük hatırlatmalarla birleştiren, yaşamın dört yönünü dengelemeyi hedefleyen Android uygulamasıdır.

> **"Pusula sadece yönü değil, hayatı hizalar."**

## 🧭 Dört Boyutlu Pusula

| Yön | Boyut | İçerik |
|-----|-------|--------|
| Kuzey | Manevi | Dinamik kıble pusulası, akıllı vakitler, zikirmatik |
| Doğu | Fiziksel | Adım sayar, su takibi |
| Güney | Zihinsel | Günün ayeti/hadisi, odak zamanlayıcı |
| Batı | Pratik | Çevrimdışı çalışma, konum senkronu |

## 🛠️ Teknolojiler

- Native Android (Gradle)
- Cihaz sensörleri: manyetometre, ivmeölçer, jiroskop
